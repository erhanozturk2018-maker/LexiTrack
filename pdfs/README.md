# Source PDFs

Put the PDFs you want to import here. The folder is ignored by Git so that your
own documents — and any copyrighted word lists — stay out of the repository.

LexiTrack was developed and validated against the two official Oxford lists:

- `The_Oxford_3000_by_CEFR_level.pdf`
- `The_Oxford_5000_by_CEFR_level.pdf`

Both are published by Oxford University Press and can be downloaded from the
Oxford Learner's Dictionaries website. Any other text-based PDF works too, via
the generic parser.
